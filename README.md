# GitOps Progressive Delivery with Argo CD & Argo Rollouts

Declarative multi-environment application delivery platform using Argo CD App-of-Apps, Argo Rollouts, and Prometheus analysis metrics.

## Key Capabilities
- **App-of-Apps & ApplicationSets**: Multi-cluster GitOps reconciliation with automated drift detection.
- **Blue/Green & Canary Delivery**: Metric-gated rollouts with automated rollback on probe failure or latency spikes.
